โฟลเดอร์สื่อ คาบ 6 (ม.1) — สร้างโดย build_period_media.js (ไฟล์นี้ถูกเขียนทับเมื่อ build ใหม่)

วิธีใส่ไฟล์: ตั้งชื่อไฟล์ให้ตรงช่องด้านล่าง แล้ววางในโฟลเดอร์นี้ (app/media/m1/p06/)
นามสกุลที่รับ: เสียง mp3 m4a aac ogg oga opus wav · วิดีโอ mp4 webm m4v mov
ใช้ลิงก์แทนไฟล์: สร้างไฟล์ meta.json เช่น {"p6_fanfare": {"url": "https://…", "credit": "ที่มา/สิทธิ์ใช้งาน"}}
ใส่ที่มา/สิทธิ์ใช้งาน (credit) ทุกไฟล์ที่ไม่ใช่ของครูเอง — ระบบจะไม่เดาที่มาให้
แล้วรัน: node tools/curriculum/build_period_media.js  (หรือ push ให้ GitHub Actions รันให้ตอน deploy)

 - p6_perfect4_song.<นามสกุล>  [เสียง]  บทเพลงที่ใช้ขั้นคู่ 4 เพอร์เฟกต์ (ครูเลือกเพลง)  (วก.5 คาบ 6 ขั้นนำ ข้อ 1)
