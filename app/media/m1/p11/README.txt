โฟลเดอร์สื่อ คาบ 11 (ม.1) — สร้างโดย build_period_media.js (ไฟล์นี้ถูกเขียนทับเมื่อ build ใหม่)

วิธีใส่ไฟล์: ตั้งชื่อไฟล์ให้ตรงช่องด้านล่าง แล้ววางในโฟลเดอร์นี้ (app/media/m1/p11/)
นามสกุลที่รับ: เสียง mp3 m4a aac ogg oga opus wav · วิดีโอ mp4 webm m4v mov
ใช้ลิงก์แทนไฟล์: สร้างไฟล์ meta.json เช่น {"p11_exam_listening": {"url": "https://…", "credit": "ที่มา/สิทธิ์ใช้งาน"}}
ใส่ที่มา/สิทธิ์ใช้งาน (credit) ทุกไฟล์ที่ไม่ใช่ของครูเอง — ระบบจะไม่เดาที่มาให้
แล้วรัน: node tools/curriculum/build_period_media.js  (หรือ push ให้ GitHub Actions รันให้ตอน deploy)

ช่องที่ วก.5 กำหนด:
 - p11_exam_listening.<นามสกุล>  [เสียง]  ข้อสอบฟังคลิปเสียงจำแนกขั้นคู่ 3, 4 และจังหวะเคาะ 70-75 BPM (ไฟล์เสียงของข้อสอบ — จำนวนข้อ วก.5 ไม่ระบุ)  (วก.5 คาบ 11 ขั้นสอบ ข้อ 3)  — ใช้กับข้อสอบ ต้องมีตัวเล่นเสียงในระบบสอบก่อน

คำแนะนำไฟล์: ขนาดเล็กลงจะโหลดไวบนมือถือ (เสียง mp3/m4a ≤ ~3 MB ต่อไฟล์ เป็นแนวทาง ไม่ใช่เงื่อนไขของระบบ) · ไฟล์ในโฟลเดอร์นี้ไม่ถูกแคชออฟไลน์อัตโนมัติ
