โฟลเดอร์สื่อ คาบ 10 (ม.1) — สร้างโดย build_period_media.js (ไฟล์นี้ถูกเขียนทับเมื่อ build ใหม่)

วิธีใส่ไฟล์: ตั้งชื่อไฟล์ให้ตรงช่องด้านล่าง แล้ววางในโฟลเดอร์นี้ (app/media/m1/p10/)
นามสกุลที่รับ: เสียง mp3 m4a aac ogg oga opus wav · วิดีโอ mp4 webm m4v mov
ใช้ลิงก์แทนไฟล์: สร้างไฟล์ meta.json เช่น {"p10_song2_audio": {"url": "https://…", "credit": "ที่มา/สิทธิ์ใช้งาน"}}
ใส่ที่มา/สิทธิ์ใช้งาน (credit) ทุกไฟล์ที่ไม่ใช่ของครูเอง — ระบบจะไม่เดาที่มาให้
แล้วรัน: node tools/curriculum/build_period_media.js  (หรือ push ให้ GitHub Actions รันให้ตอน deploy)
