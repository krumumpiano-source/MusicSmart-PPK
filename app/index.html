* ข้อมูลจะถูกบันทึกทั้งในเครื่องและ Google Sheets อัตโนมัติ
⚡ วิธีสร้าง Google Sheet เชื่อมต่อ (ทำครั้งเดียวใน 1 นาที):
  1. เปิด Google Sheets เปล่าขึ้นมา 1 ไฟล์ใน Google Drive ของคุณครู (ตั้งชื่อเช่น MusicSmart_PPK_Database)
  2. ไปที่เมนูด้านบน ส่วนขยาย (Extensions) ➔ Apps Script
  3. ลบโค้ดเดิมในนั้นออกทั้งหมด แล้วกดปุ่มสีเขียวด้านบน "คัดลอกโค้ด Google Apps Script" นำไปวางในหน้าต่าง Apps Script แล้วกดปุ่มแผ่นดิสก์ 💾 บันทึก
  4. กดปุ่มสีน้ำเงิน "ทำให้ใช้งานได้" (Deploy) ➔ "การทำให้ใช้งานได้ใหม่" (New deployment)
    ⚠️ จุดสำคัญมาก: ในช่อง "ผู้มีสิทธิ์เข้าถึง" (Who has access) ให้เลือกเป็น "ทุกคน" (Anyone) จากนั้นกด Deploy และคัดลอก URL เว็บแอปมาวางในช่องด้านบน
ดูตัวอย่างโค้ด Google Apps Script (.gs) 
function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.tryLock(20000);
  try {
    var payload = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    processSyncItem(ss, payload);
    return ContentService.createTextOutput(JSON.stringify({status:'success'}))
      .setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}
