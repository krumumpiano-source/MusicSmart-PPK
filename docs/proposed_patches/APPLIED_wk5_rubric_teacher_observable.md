# ข้อเสนอแก้ถ้อยคำเกณฑ์ วก.5 ม.1 (คาบฝึกคาลิมบ้า) — **ใช้จริงแล้ว (APPLIED) — ครูอนุมัติ ข้อ ก เมื่อ 28 ต.ค. 2569**

สร้างโดย `tools/curriculum/propose_rubric_patch.js` (ช่อง "ก่อนแก้" อ่านจากข้อมูลในแอปตอนรัน) — ไม่ได้แก้ docx และไม่ได้แก้ข้อมูลในแอป

## เหตุผล

1. ถ้อยคำเดิมอ้างค่าความคลาดเคลื่อนเป็นมิลลิวินาที (±35 ms ฯลฯ) และ "ระบบตรวจจับ/ให้คะแนนอัตโนมัติ" ซึ่ง **แอปไม่ได้ทำ** — ในการใช้งานจริงครูสังเกตและให้คะแนนหน้างานเอง
2. เกณฑ์ทักษะ (P) เดิมเน้นจังหวะอย่างเดียว ไม่ได้ประเมิน **ความถูกต้องของโน้ต (ตำแหน่งลิ่ม/ระดับเสียง)** — ข้อเสนอนี้ให้ทั้ง 2 ด้านอยู่ในทุกระดับ: (ก) ถูกตำแหน่งลิ่มกี่ตัว (ข) ตรงจังหวะกับเมโทรนอม
3. ตัวเลขที่ครูนับได้ด้วยตา/หู: จำนวนโน้ตที่ผิดหรือข้าม และจำนวนครั้งที่สะดุด (ตัวเลขเหล่านี้เป็นข้อเสนอเริ่มต้น ครูปรับได้)
4. ชื่อบทเพลงคาบ 8–10 เปลี่ยนตามแพตช์ Joy to the World (t49u) แยกต่างหาก — ไฟล์นี้ไม่แตะชื่อเพลง
