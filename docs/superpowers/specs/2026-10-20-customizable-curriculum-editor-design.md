# พิมพ์เขียวการพัฒนาระบบปรับแต่งแผนการสอนอย่างอิสระ (Customizable Curriculum & Lesson Plan Editor)
**โรงเรียนพะเยาพิทยาคม • กลุ่มสาระการเรียนรู้ศิลปะ (สาระดนตรี)**
**วันที่จัดทำ:** 20 ตุลาคม 2569 | **สถานะ:** เสนออนุมัติ (Proposed)

---

## 1. วัตถุประสงค์ (Objectives)
1. ให้คุณครูผู้สอนสามารถปรับแต่ง แก้ไข เพิ่มเติม หรือลดทอนทุกองค์ประกอบของแผนการสอน (ทั้ง ม.1 และ ม.2 รวม 40 คาบ) ได้อย่างอิสระ 100%
2. ปรับเวลานาทีและกิจกรรมใน 5 ขั้นตอน T-PACE (Tune-in, Present, Apply, Check, Evaluate) แล้วส่งผลให้นาฬิกาดิจิทัลนับถอยหลังในห้องเรียน (Cockpit Countdown Timer) ปรับตามเวลาที่กำหนดใหม่อัตโนมัติ
3. เพิ่ม ลบ หรือแก้ไขสื่อการสอน ลิงก์คลิป YouTube, Google Drive, หรือเอกสารแนบในแต่ละคาบได้ตามบริบทชั้นเรียน
4. รองรับความปลอดภัยในการจัดการข้อมูล มีระบบ **"คืนค่าแผนมาตรฐานโรงเรียน" (Reset to Default)** ทั้งแบบรายคาบ และแบบคืนค่าทั้งหลักสูตร
5. ข้อมูลที่ครูปรับแต่งจะถูกจัดเก็บแบบ Local-First (ออฟไลน์ได้) และซิงค์ขึ้น Google Sheets (แท็บ `แผนการสอน_Curriculum`) อัตโนมัติเพื่อให้ทุกเครื่องใช้งานข้อมูลชุดเดียวกัน

## 2. สถาปัตยกรรมข้อมูล (Data Architecture & Overlay Pattern)

### 2.1 โครงสร้าง Overlay Pattern
- **Base Layer (ฐานข้อมูลหลัก):** `LESSONS_DATA` ใน `app/data/lessons.js` เป็นแผนแม่บทมาตรฐาน 40 คาบของโรงเรียน (Read-only, ปลอดภัย ไม่ถูกเขียนทับถาวร)
- **Custom Layer (ชั้นข้อมูลที่ครูแก้ไข):** บันทึกใน LocalStorage คีย์ `ppk_custom_lessons` โดยเก็บเป็น Object:
  ```json
  {
    "M1": {
      "1": { "topic": "...", "kpa": {...}, "steps": [...], "media": [...], "mentor_tips": "..." }
    },
    "M2": {
      "1": { ... }
    }
  }
  ```
- **Resolution Strategy:**
  - `Store.getLesson(grade, period)`:
    1. ตรวจสอบใน `ppk_custom_lessons` ก่อน หากมี ให้ผสาน (Deep Merge) กับ Base Lesson เพื่อให้ฟิลด์ที่ไม่ได้แก้อยู่ครบ
    2. หากไม่มีใน Custom Layer ให้ดึงจาก Base `LESSONS_DATA` ตามปกติ
  - `Store.saveCustomLesson(grade, period, customData)`:
    1. บันทึกลง LocalStorage
    2. ล้าง Lesson Cache Map ใน Store เพื่อให้ได้ข้อมูลสดทันที
    3. เรียก `GoogleSheetSync.syncCurriculumUpdate(grade, period, customData)` ส่งขึ้น Google Sheet
  - `Store.resetCustomLesson(grade, period)`:
    - ลบเฉพาะคาบนั้นออกจาก Custom Layer เพื่อกลับสู่แผนมาตรฐานทันที
  - `Store.resetAllCustomLessons()`:
    - ลบ Custom Layer ทั้งหมด คืนค่าทั้ง 40 คาบกลับสู่มาตรฐานโรงเรียน

## 3. องค์ประกอบหน้าจอผู้ใช้ (User Interface & User Flow)

### 3.1 จุดเข้าใช้งาน (Access Points)
1. **Quick-Edit ในห้องเรียน (Cockpit):**
   - ที่แท็บ `บทเรียน` (Tab 1) ด้านบนขวา เพิ่มปุ่ม:
     `✏️ ปรับแต่งแผนการสอนคาบนี้`
   - เมื่อคลิก จะเปิด Modal ปรับแต่งเฉพาะคาบปัจจุบันขึ้นมาทันที พร้อมโหลดค่าเดิมลงในฟอร์ม
2. **Curriculum Manager (ศูนย์จัดการหลักสูตร 40 คาบ):**
   - ที่แถบเมนูด้านบน (Header Navigation) เพิ่มปุ่ม:
     `📚 คลังแผนการสอน (Curriculum Hub)`
   - แสดงตารางภาพรวม 20 คาบ ม.1 (ศ21101/ศ21102) และ 20 คาบ ม.2 (ศ22101/ศ22102) มีป้ายบอกว่าคาบใดเป็นแผนมาตรฐาน หรือคาบใดมี "✏️ มีการปรับแต่งเอง" พร้อมปุ่มกดแก้ไขและดูตัวอย่าง

### 3.2 ฟิลด์ที่แก้ไขได้ในแต่ละแผนการสอน
| หมวดหมู่ | ฟิลด์ | รายละเอียดการแก้ไข |
|---|---|---|
| **ข้อมูลทั่วไป** | Unit Name, Topic, Duration | ชื่อหน่วยการเรียนรู้, ชื่อเรื่อง/หัวข้อ, เวลารวม (นาที) |
| **จุดประสงค์ KPA** | K (Knowledge) | มาตรฐาน/ตัวชี้วัด และความรู้ที่ต้องการให้เกิด |
| | P (Process/Practice) | ทักษะการปฏิบัติ (เช่น การเคาะนิ้ว, ดีดคาลิมบ้า) |
| | A (Attitude) | คุณลักษณะอันพึงประสงค์ วินัย ความรับผิดชอบ |
| **ขั้นตอน 5 ขั้น T-PACE** | Steps 1-5 | แต่ละขั้นระบุ: ชื่อขั้น, นาที (ส่งผลต่อ Timer), กิจกรรมของครูและนักเรียน |
| **คำแนะนำนิเทศ** | Mentor Tips | ข้อเสนอแนะสำหรับครูผู้สอนและนักศึกษาฝึกสอน |
| **สื่อและนวัตกรรม** | Media Items | รายการสื่อ: ชื่อสื่อ, ประเภท (YouTube, Drive, PDF, เว็บไซต์), URL ลิงก์ |
| **การวัดประเมินผล** | Assessment | รูบริกการให้คะแนน หรือแบบทดสอบประจำคาบ |

## 4. การเชื่อมโยงนาฬิกานับถอยหลัง T-PACE (Dynamic Timer Binding)
- ฟังก์ชัน `App.getTpacePhases()` จะดึงเวลา `step.duration` จาก `Store.getLesson()` ล่าสุดเสมอ
- หากคุณครูแก้เวลา เช่น ขั้น P: จาก 10 นาที เป็น 20 นาที นาฬิกาในแถบ T-PACE Phase Bar และ Cockpit Digital Timer จะขยายเวลานับถอยหลังตามที่กำหนดใหม่ทันทีโดยไม่ต้องรีเฟรชหน้าเว็บ

---

## 5. การซิงค์คู่ขนาน Google Sheets (Dual-Save Engine)
- ใน `google_apps_script.js` เพิ่มการรองรับ `type: 'curriculum_lesson'`
- เพิ่มแท็บใน Google Sheet: `แผนการสอน_Curriculum`
  - คอลัมน์: วันเวลาที่แก้ไข, ระดับชั้น (ม.1/ม.2), คาบที่, ชื่อหน่วย, หัวข้อบทเรียน, KPA, เวลา T-PACE (นาที), กิจกรรม, สื่อการสอน, ผู้แก้ไข
- คุณครูและครูร่วมสอนที่เปิดโปรแกรมจากเครื่องอื่น สามารถกดซิงค์เพื่อรับแผนการสอนที่ปรับแต่งล่าสุดไปใช้ร่วมกันได้ทันที

## 6. แผนการตรวจสอบและทดสอบ (Verification Plan)
1. **Unit & Store Tests:**
   - ทดสอบ `Store.saveCustomLesson`, `Store.getLesson`, `Store.resetCustomLesson`
   - ตรวจสอบว่า `LESSONS_DATA` ต้นฉบับไม่ถูกแก้ไขโดยตรง (Immutability check)
2. **UI & DOM Tests:**
   - ทดสอบการเปิด/ปิด Modal แก้ไขแผนทั้งจากใน Cockpit และจาก Curriculum Manager
   - ทดสอบการกดบันทึกแล้วค่าบนหน้าจอ Cockpit เปลี่ยนแปลงทันที (Topic, KPA, Timeline steps, Media links)
   - ทดสอบว่าการปรับเวลาขั้นตอน T-PACE ส่งผลให้นาฬิกานับถอยหลังคำนวณเวลารวมถูกต้อง
3. **Reset to Default Test:**
   - ทดสอบการกดปุ่มคืนค่ามาตรฐาน ข้อมูลต้องกลับเป็นค่าเริ่มต้นของโรงเรียนทันที
4. **Google Sheets Sync Test:**
   - ทดสอบส่ง payload `curriculum_lesson` ไปยัง Google Apps Script และตรวจสอบผลลัพธ์
