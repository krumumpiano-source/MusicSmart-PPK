# ระบบเข้าสู่ระบบนักเรียน • ติดตั้งแอป • มุมมองตามบทบาท

## นักเรียนเข้าใช้ครั้งแรก
1. เปิดลิงก์นักเรียนที่ครูส่งให้ (มี `?role=student&api=...`)
2. กรอกรหัสนักเรียน 5 หลัก → ระบบตรวจกับ Google Sheet ของครู (แสดงเพียงห้องและอักษรตัวแรกของชื่อ)
3. ครั้งแรก: บังคับตั้ง PIN 6 หลัก (กรอก 2 ครั้ง) แล้วเข้าระบบทันที
4. ครั้งต่อไป: รหัส + PIN • ผิด 5 ครั้ง ล็อก 15 นาที • ลืม PIN ให้ครูรีเซ็ต

PIN เก็บเป็น SHA-256 + salt + pepper (Script Property `PIN_PEPPER` สร้างอัตโนมัติ) ไม่เก็บตัวเลข PIN
ถ้ายังไม่ได้ตั้ง URL ระบบจะใช้รายชื่อในเครื่อง (โหมดสาธิต/ทดสอบ ใช้รายชื่อตัวอย่าง)

## ติดตั้งแอปบนมือถือ
แถบ "ติดตั้งแอป MusicSmart ลงบนมือถือ" แสดงบนมือถือ (Android: ปุ่มติดตั้งเลย, iPhone: วิธีเพิ่มไปยังหน้าจอโฮม)
ไม่แสดงเมื่อเปิดจากแอปที่ติดตั้งแล้ว กด "ไว้ทีหลัง" จะซ่อน 7 วัน

## นักเรียนเห็นอะไร
เห็น: ภาระงาน/งานซ่อม, เนื้อหาและสื่อที่ต้องเรียน, เป้าหมาย K-P-A, แบบทดสอบ, คะแนน/เวลาเรียนของตัวเอง, คำแนะนำครูต่องานของตัวเอง
ไม่เห็น (ถูกลบออกจาก DOM ไม่ใช่แค่ซ่อน): ขั้นตอนการสอน, คำแนะนำครูพี่เลี้ยง, รูบริกของครู, เฉลยข้อสอบ, ข้อมูลนักเรียนคนอื่น, หน้าครูทั้งหมด
ครูเห็นทุกอย่างเหมือนเดิม
