# MusicSmart • ฟีเจอร์เพิ่มเติม (Phase 1–4)

## Phase 1: กำหนดส่ง + แบบทดสอบตรวจบนเซิร์ฟเวอร์
- ครูตั้งกำหนดส่งต่อห้อง/คาบในหน้าตรวจงาน (📅 แถบด้านบนรายการงาน) เวลาเป็นเวลาไทย → ชีต `กำหนดส่ง_DueDates`
- เซิร์ฟเวอร์ตัดสิน "ส่งช้า" = ได้รับหลังกำหนดส่ง (คอลัมน์ late ใน `นักเรียนส่งงาน_Inbox`) ถ้าไม่มีกำหนดส่ง ใช้เกณฑ์เดิม (หลังบันทึกคาบเกิน 7 วัน)
- ครูกด "📝 อัปโหลดคลังข้อสอบ" (จัดการผู้ใช้ > นักเรียน) → ชีต `คลังข้อสอบ_QuizBank` (มีเฉลย อยู่ในชีตครูเท่านั้น)
- มือถือนักเรียนรับข้อสอบผ่าน `studentQuizGet` (ไม่มีเฉลย/คำอธิบาย) ส่งคำตอบ (`quiz_answers`) → เซิร์ฟเวอร์ตรวจ บันทึกคะแนน และตอบกลับเฉพาะคะแนน
- เซิร์ฟเวอร์ไม่รับคะแนนที่คิดในเครื่องนักเรียนแล้ว (kind `quiz` ถูกปฏิเสธ)
- นักเรียนเห็นกำหนดส่งของห้องตัวเอง (`studentTasks`) และป้าย "เลยกำหนดส่ง"
- หน้าครูยังใช้ quizzes.js (มีเฉลยละเอียด) เหมือนเดิม

## Phase 2: เครื่องมือครู
- หน้าตรวจงาน: ปุ่ม "🔔 ทวงงานผู้ยังไม่ส่ง" → ชีต `แจ้งเตือน_Notices` นักเรียนเห็นข้อความ "📣 ข้อความจากคุณครู" เมื่อเปิดแอปครั้งถัดไป (เห็นเฉพาะของตัวเอง)
- บันทึกคำแนะนำ/คะแนนในหน้าตรวจงาน → ส่งถึงมือถือนักเรียนอัตโนมัติ แสดงในการ์ด "คำแนะนำจากคุณครู" ของงานนั้น
- ปุ่ม "📊 แดชบอร์ด": รายห้อง (เวลาเรียนเฉลี่ย กลุ่มเสี่ยง งานค้าง) และรายบุคคล (คะแนนรายคาบ แบบทดสอบ เวลาเรียน)
  - กลุ่มเสี่ยง: เวลาเรียน < 80% หรือค้างส่ง ≥ 3 ชิ้น หรือคะแนนแบบทดสอบเฉลี่ย < 50%
  - "ค้างส่ง" นับคาบที่ครูบันทึกแล้ว หรือเลยกำหนดส่งแล้ว แต่ยังไม่มีงาน
- ส่งออก Excel (.xlsx ถ้าโหลดไลบรารีได้) / CSV (UTF-8 BOM เปิดใน Excel ได้) รูปแบบคล้าย ปพ.5
  - สมมติฐาน: คะแนนเก็บคาบละเต็ม 3 (20 คาบ), แบบทดสอบ 4 หน่วย, เวลาเรียน ≥ 80% = มีสิทธิ์สอบ (ต่ำกว่า = มส)
  - ใช้ข้อมูลในเครื่องครู (กด "ดึงงานนักเรียน" ก่อนส่งออก) ไม่ใช่แบบฟอร์มทางการ ต้องตรวจทานก่อนใช้จริง

## Phase 3 — นักศึกษาฝึกสอน (Intern) + ครูพี่เลี้ยง
- ครูพี่เลี้ยงสร้างบัญชี นศ. (ปุ่ม 👩‍🎓 นศ.ฝึกสอน) กำหนดห้องที่สอน; นศ. ตั้ง PIN 6 หลักครั้งแรก (hash + salt + pepper บนเซิร์ฟเวอร์)
- token ของ นศ. (HMAC, role=intern) ใช้ได้เฉพาะห้องที่ได้รับมอบหมาย; ใช้แทน token นักเรียน/รหัสซิงค์ครูไม่ได้; รีเซ็ต PIN = token เดิมใช้ไม่ได้
- นศ. เห็นเนื้อหาครู (แผน/เฉลย/rubric) แต่ไม่มีเมนูตั้งค่า จัดการผู้ใช้ รหัสซิงค์
- คะแนนที่ นศ. ให้ → คิว `รออนุมัติคะแนน_Approvals` → ครูพี่เลี้ยงอนุมัติ/ไม่อนุมัติ (อนุมัติแล้วเขียนลงบันทึกคาบของครู)
- บันทึกหลังสอนของ นศ. → `นศ_บันทึกหลังสอน` + วก5; แบบประเมินการนิเทศ 5 ด้าน (1–5) → `นิเทศ_Supervision`
- พอร์ตโฟลิโอ HTML พิมพ์/PDF ได้ (ไม่มีชื่อนักเรียน)
- ข้อจำกัด: คะแนนที่อนุมัติจะเข้าเครื่องครูเครื่องที่กดอนุมัติ; นศ. ต้องออนไลน์เพื่อซิงค์ห้องเรียน
