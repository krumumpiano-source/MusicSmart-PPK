# แผนอนาคต (ยังไม่ทำ · ไม่มีโค้ด): ปุ่ม "สุ่มเลือกกลุ่ม"

สถานะ: ครูสั่งพักไว้ — บันทึกแนวคิดเท่านั้น

- ใช้กับคาบงานกลุ่มที่นำเสนอ/เก็บคะแนนตาม วก.5: คาบ 9, 10, 13, 15, 19
- ครูกดสุ่ม → เก็บ "เหตุการณ์สุ่ม" 1 แถว (drawId, คาบ, กลุ่มที่เข้าสุ่ม, seed, เวลา, ผล) ลงชีตผ่าน Apps Script
- ผลมาจาก seed แบบกำหนดแน่นอน (ไม่ใช้ Math.random) → ทุกเครื่องเห็นผลเดียวกัน ทดสอบซ้ำได้
- เครื่องนักเรียนไม่ใช้ realtime: ตรวจครั้งเดียวตอนเปิดแอป/กลับมาที่แท็บ + ตัวจับเวลาช้า (ราว 30 วินาที) เฉพาะตอนอยู่ในคาบงานกลุ่มและแท็บเปิดอยู่
- เมื่อพบ drawId ใหม่ → เล่นวงล้อจาก seed+ผล แล้วขึ้นป๊อบอัพ (กลุ่มที่ถูกเลือกเห็นข้อความต่างจากกลุ่มอื่น) ครั้งเดียวต่อ drawId; เหตุการณ์เก่าเกินเวลาที่ครูตั้งไม่เด้ง แต่ดูในประวัติได้
- ตัวเลือก: ไม่สุ่มซ้ำกลุ่มที่ถูกเลือกแล้ว, ยกเลิก/สุ่มใหม่ (เก็บประวัติ), เคารพ prefers-reduced-motion
- ทางเลือกที่ต้องประเมินตอนทำจริง: (ก) โพลเบา (ข) วงล้อบนจอครู/โปรเจคเตอร์เป็นหลัก (ค) QR/รหัสสั้น — พร้อมประมาณจำนวนครั้งเรียก Apps Script ต่อชั่วโมงและผลต่อแบตเตอรี่
