# ชุดเครื่องมือวัดและประเมินผล (Assessment Tools) - Phase 1 (อัปเกรดระดับ คศ.4)
**วิชา:** ดนตรี 1 (คาลิมบ้า) ม.1
**หน่วยที่ครอบคลุม:** หน่วยที่ 1 (พื้นฐานคาลิมบ้า) และ หน่วยที่ 2 (ปฏิบัติรวมวงคาลิมบ้า)

## 🎵 1. แบบประเมินทักษะปฏิบัติคาลิมบ้าเดี่ยว (Rubrics)
**ใช้สำหรับ:** ประเมินการสอบปฏิบัติ เทียบเสียง เล่นสเกล และบทเพลงสั้น (หน่วยที่ 1)

| ประเด็นการประเมิน | ดีเยี่ยม (4) | ดี (3) | พอใช้ (2) | ปรับปรุง (1) |
| :--- | :--- | :--- | :--- | :--- |
| **1. การจูนเสียง (Blind Tuning)** | เทียบเสียงได้ตรงทุกคีย์อย่างคล่องแคล่ว และสามารถฟังจำแนกระดับเสียงเพี้ยนและแก้ไขได้ด้วยตนเองโดยไม่พึ่งพาแอปพลิเคชัน | เทียบเสียงได้ตรงเป็นส่วนใหญ่ แต่ยังต้องพึ่งพาแอปพลิเคชันช่วยในการยืนยันความถูกต้องในบางช่วง | เทียบเสียงได้ แต่ไม่สามารถรับรู้เสียงเพี้ยนด้วยหูตนเอง ต้องพึ่งพาแอปพลิเคชันหรือครูชี้แนะตลอด | ไม่สามารถเทียบเสียงและไม่รับรู้ระดับเสียงที่เพี้ยนได้เลย |
| **2. ท่าทางการจับ (Posture & Technique)** | จับมั่นคง ถูกสรีระ กรีดนิ้วและประคองน้ำหนักมือได้อย่างเป็นธรรมชาติ ส่งเสริมให้เกิดความกังวานของเสียงที่ดี | จับมั่นคง ถูกสรีระ วางนิ้วถูกต้องเป็นส่วนใหญ่ แต่ยังขาดความพริ้วไหวเล็กน้อย | จับเครื่องดนตรีได้ แต่วางนิ้วผิดสรีระบางจุด ทำให้เกิดความเกร็งและจำกัดการสั่นสะเทือนของเสียง | จับเครื่องดนตรีไม่ถนัด วางนิ้วผิดวิธี ส่งผลให้เสียงตีบอดอย่างชัดเจน |
| **3. ความเป็นดนตรี (Musicality & Accuracy)** | บรรเลงโน้ตแม่นยำ พร้อมทั้งใช้ระดับความดัง-เบา (Dynamics) สอดคล้องกับทิศทางของทำนอง (Phrasing) ได้อย่างชัดเจนอย่างน้อย 3 จุดในบทเพลง | บรรเลงโน้ตถูกต้องเป็นส่วนใหญ่ เริ่มมีการควบคุมน้ำหนักเสียงบ้างแต่อาจยังไม่ชัดเจนหรือขาดความลื่นไหล | บรรเลงโน้ตผิดพลาดหลายจุด ขาดการควบคุมน้ำหนักเสียง เล่นเสียงระดับเดียวกันตลอดทั้งเพลง | บรรเลงโน้ตผิดพลาดจนขาดความเป็นเพลง และไม่สามารถบรรเลงจนจบได้ |
| **4. จังหวะ (Rhythm & Tempo)** | บรรเลงตรงจังหวะ มีความสม่ำเสมอ และเน้นน้ำหนักจังหวะตก (Accent) ได้อย่างถูกต้องสม่ำเสมอตลอดทั้งบทเพลง | บรรเลงตรงจังหวะเป็นส่วนใหญ่ มีคร่อมจังหวะบ้างเล็กน้อยแต่ยังดึงกลับเข้าจังหวะเดิมได้ | บรรเลงคร่อมจังหวะบ่อยครั้ง ความเร็วไม่สม่ำเสมอตามอารมณ์ตนเอง ไม่สัมพันธ์กับโครงสร้างเพลง | ไม่สามารถรักษาจังหวะได้เลย ต้องหยุดเล่นบ่อยครั้ง ขาดความเข้าใจเรื่องอัตราจังหวะ |
| **5. การถอดรหัสจังหวะ (Rhythm Dictation)** | ฟังและแปลงเสียงเป็นสัญลักษณ์จังหวะ (Rhythm Dictation) ได้ถูกต้องแม่นยำ 100% | แปลงเสียงเป็นสัญลักษณ์จังหวะได้ถูกต้อง 80% มีข้อผิดพลาดในจังหวะย่อยเล็กน้อย | แปลงเสียงเป็นสัญลักษณ์จังหวะได้ถูกต้อง 50% สามารถระบุได้เฉพาะจังหวะตกหลัก | ไม่สามารถระบุความแตกต่างของสัญลักษณ์จังหวะที่ได้ยินได้เลย |

## 🤝 2. แบบประเมินทักษะรวมวงคาลิมบ้า Mini-Recital (Rubrics)
**ใช้สำหรับ:** ประเมินการบรรเลงเพลงรวมวงและการแก้ปัญหาเฉพาะหน้าทางดนตรี (หน่วยที่ 2)

| ประเด็นการประเมิน | ดีเยี่ยม (4) | ดี (3) | พอใช้ (2) | ปรับปรุง (1) |
| :--- | :--- | :--- | :--- | :--- |
| **1. การสื่อสารและสมดุลเสียง (Ensemble & Balance)** | สื่อสารผ่านอวัจนภาษา (Eye Contact) ตลอดเวลา รักษาระดับความดังของคอร์ดประสาน ไม่ให้กลบเสียงทำนองหลัก (Melody) ตลอดการบรรเลงรวมวง | พยายามสื่อสารในวง รักษาสมดุลเสียงได้เป็นส่วนใหญ่ แต่อาจมีบางพาร์ทที่เสียงดังกลบทำนองหลัก | เล่นตามวงได้บ้าง แต่เน้นก้มหน้าอ่านโน้ต ขาดการฟังเสียงเพื่อนร่วมวง ทำให้สมดุลเสียงขาดหาย | เล่นไม่ตรงจังหวะวง ไม่ฟังเสียงผู้อื่น ทำให้วงล่มหรือเกิดความสับสนอย่างหนัก |
| **2. ปฏิภาณไหวพริบ (Problem Solving)** | มีไหวพริบในการประคองวงเมื่อมีความผิดพลาดเฉพาะหน้า (เช่น ด้นสดทดแทน, ดึงจังหวะกลับ) โดยไม่หยุดชะงักเกิน 1 จังหวะ | สามารถตั้งสติและดึงจังหวะกลับเข้าสู่วงได้เร็วเมื่อเกิดความผิดพลาด แต่อาจมีชะงักเล็กน้อย | หยุดเล่นเมื่อเกิดความผิดพลาด และต้องใช้เวลาในการจับจังหวะเพื่อเข้าวงใหม่ | หยุดเล่นถาวรเมื่อเกิดความผิดพลาด ไม่สามารถประคองหรือซัพพอร์ตวงให้เล่นต่อได้ |
| **3. การนำเสนอ (Performance & Interpretation)** | ใช้ระดับความดัง-เบา (Dynamics) และจังหวะยืดหยุ่น (Rubato) สอดคล้องกับทิศทางของทำนอง (Phrasing) ได้อย่างชัดเจน พร้อมแสดงออกด้วยความมั่นใจ | มีความมั่นใจ สื่ออารมณ์เพลงได้ระดับหนึ่ง และพยายามมีปฏิสัมพันธ์กับผู้ชม | ขาดความมั่นใจ ขาดการสื่ออารมณ์เพลง เล่นเสมือนการท่องจำและก้มหน้ามองแต่เครื่องดนตรี | แสดงออกถึงความกังวลอย่างชัดเจนจนส่งผลกระทบต่อคุณภาพของการบรรเลงรวมวง |

## 🛠️ 3. แบบประเมินทักษะทางสังคมและวินัยนักดนตรี (Affective Domain)
**ใช้สำหรับ:** ประเมินคุณลักษณะ A เชิงประจักษ์ ระหว่างเรียน (หน่วยที่ 1 และ 2)

| รายการพฤติกรรมที่สังเกต | ปฏิบัติสม่ำเสมอ (2) | ปฏิบัติบางครั้ง (1) | ไม่ปฏิบัติ (0) |
| :--- | :---: | :---: | :---: |
| 1. วิเคราะห์ข้อบกพร่องทางเทคนิคของตนเองและหาวิธีปรับปรุงได้อย่างสมเหตุสมผล | | | |
| 2. เสนอแนะวิธีฝึกซ้อม (Practice Strategy) ช่วยเพื่อนแก้ปัญหาทางดนตรีได้อย่างถูกต้องและสร้างสรรค์ | | | |
| 3. เคารพความแตกต่างทางทักษะของเพื่อนร่วมวง และให้กำลังใจเชิงบวกเสมอ | | | |
| 4. มีความตระหนักรู้ต่อการทำงานร่วมกัน รับฟังความเห็นและปรับจูนเข้าหาเป้าหมายวง | | | |
| 5. บำรุงรักษาและจัดเก็บเครื่องดนตรีด้วยความรับผิดชอบและถูกหลักการอย่างสม่ำเสมอ | | | |

## 🗣️ 4. แบบประเมินเพื่อนวิพากษ์เพื่อน (Peer Critique) ระดับวิเคราะห์
**ใช้สำหรับ:** ประเมินวงเพื่อนหลังการแสดง

| มิติการวิพากษ์ทางดนตรี | ชัดเจนและวิเคราะห์เชิงลึก (3) | อธิบายได้ทั่วไป (2) | ไม่ใช้หลักการทางดนตรี (1) |
| :--- | :---: | :---: | :---: |
| 1. จุดแข็งด้านเทคนิค/การรวมวง (พร้อมระบุเหตุผลทางดนตรีประกอบ) | | | |
| 2. จุดบกพร่องทางดนตรีที่ตรวจพบ (เช่น จังหวะ, น้ำหนักเสียง, ความกลมกลืน) | | | |
| 3. ข้อเสนอแนะเชิงปฏิบัติ (Actionable Feedback) และวิธีการฝึกซ้อมเพื่อแก้ปัญหาข้อ 2 | | | |
