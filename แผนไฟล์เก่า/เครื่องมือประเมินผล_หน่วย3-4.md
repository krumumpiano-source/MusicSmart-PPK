# ชุดเครื่องมือวัดและประเมินผล (Assessment Tools) - Phase 2 (อัปเกรดระดับ คศ.4)
**วิชา:** ดนตรี 1 (คาลิมบ้า) ม.1
**หน่วยที่ครอบคลุม:** หน่วยที่ 3 (รอบรู้วงดนตรีและวัฒนธรรม) และ หน่วยที่ 4 (สุนทรียภาพแห่งการฟัง)

## 🎙️ 1. แบบประเมินทักษะการจัดทำ Digital Audio Guide / Podcast (Rubrics)
**ใช้สำหรับ:** ประเมินทักษะการวิเคราะห์ดนตรีต่างวัฒนธรรมผ่านสื่อดิจิทัล (หน่วยที่ 3)

| ประเด็นการประเมิน | ดีเยี่ยม (4) | ดี (3) | พอใช้ (2) | ปรับปรุง (1) |
| :--- | :--- | :--- | :--- | :--- |
| **1. การวิเคราะห์เนื้อหา (Analysis)** | วิเคราะห์ประวัติและเปรียบเทียบเครื่องดนตรีต่างวัฒนธรรม โดยอ้างอิงหลักฐานทางประวัติศาสตร์และองค์ประกอบทางดนตรีมารองรับได้อย่างน้อย 3 ประเด็น | อธิบายและเปรียบเทียบเครื่องดนตรีได้ถูกต้องครบถ้วนตามทฤษฎี แต่อาจขาดการวิเคราะห์เชิงลึกที่เชื่อมโยงบริบท | อธิบายเนื้อหาได้กว้างๆ ข้อมูลถูกต้องบางส่วน ไม่มีการเปรียบเทียบเชิงลึก | ข้อมูลผิดพลาด ขาดการวิเคราะห์ และไม่ได้แสดงถึงความเข้าใจในความแตกต่างทางวัฒนธรรม |
| **2. การถ่ายทอด (Storytelling)** | ลำดับเรื่องราวผ่านน้ำเสียงที่มีจังหวะจะโคน สามารถเชื่อมโยงบริบททางดนตรีให้ผู้ฟังเห็นภาพและคล้อยตาม | เล่าเรื่องได้ลื่นไหล ชัดเจน และน่าติดตาม แต่อาจยังขาดความดึงดูดในบางช่วง | การเล่าเรื่องคล้ายการอ่านสคริปต์ ขาดอารมณ์ร่วม ไม่ดึงดูดความสนใจผู้ฟัง | พูดตะกุกตะกัก จับใจความไม่ได้ ลำดับเรื่องราวสับสน |
| **3. สุนทรียภาพของเสียง (Audio Aesthetics)** | คุณภาพเสียงชัดเจน ออกแบบดนตรีประกอบ (BGM) และ Sound Effects ที่สอดคล้องกับจังหวะการเล่าเรื่อง (Pacing) เพื่อกระตุ้นอารมณ์ผู้ฟังได้อย่างกลมกลืน | คุณภาพเสียงชัดเจน มีการใช้ BGM อย่างเหมาะสม แต่อาจไม่ส่งเสริมอารมณ์ของเนื้อหาเท่าที่ควร | ใช้ BGM แบบสุ่ม ไม่มีความเกี่ยวข้องกับเนื้อหา หรือระดับเสียงกลบเสียงผู้บรรยาย | ไม่มี BGM คุณภาพเสียงแย่จนไม่สามารถสื่อสารเนื้อหาได้ |
| **4. กระบวนการกลุ่ม (Process)** | แบ่งหน้าที่ชัดเจน ทำงานอย่างเป็นระบบ และแก้ปัญหาเฉพาะหน้าระหว่างการผลิตสื่อได้อย่างมีประสิทธิภาพ | ให้ความร่วมมือในการทำงานกลุ่ม ส่งงานตรงเวลา แต่อาจต้องพึ่งพาผู้นำกลุ่มมาก | มีส่วนร่วมในงานน้อย ขาดความรับผิดชอบในบางขั้นตอน | ไม่ให้ความร่วมมือ ทิ้งภาระให้เพื่อนร่วมกลุ่ม ส่งงานล่าช้ามาก |

## 🎧 2. แบบประเมินทักษะการจัด Digital Playlist (Curation Rubrics)
**ใช้สำหรับ:** ประเมินทักษะการประเมินค่าและร้อยเรียงสุนทรียภาพทางดนตรี (หน่วยที่ 4)

| ประเด็นการประเมิน | ดีเยี่ยม (4) | ดี (3) | พอใช้ (2) | ปรับปรุง (1) |
| :--- | :--- | :--- | :--- | :--- |
| **1. กราฟอารมณ์ (Emotional Arc)** | มีธีมชัดเจนและออกแบบกราฟอารมณ์เพลง (Intro -> Climax) โดยจัดวางเพลงที่ส่งเสริมระดับความเข้มข้นทางอารมณ์ต่อเนื่องกันอย่างไม่มีสะดุด | มีธีมที่ชัดเจน จัดเรียงเพลงได้ลื่นไหล แต่อาจยังขาดมิติของการไล่ระดับอารมณ์ (Climax) | มีธีมรวมๆ เพลงมีความคล้ายคลึงกัน แต่การจัดเรียงไม่ได้ส่งเสริมการรับรู้ทางอารมณ์ที่ต่อเนื่อง | จัดกลุ่มเพลงแบบสุ่ม ไม่มีความเกี่ยวเนื่องทางอารมณ์ ขาดการออกแบบธีม |
| **2. ความสอดคล้อง (Musical Cohesion)** | เลือกเพลงที่มีความเชื่อมโยงกันทางทฤษฎีดนตรี (เช่น Tempo, โทนเสียง, ยุคสมัย) พร้อมอ้างอิงทฤษฎีการจัดเรียงได้อย่างมีตรรกะชัดเจน | เลือกเพลงได้เข้ากับธีม อธิบายเหตุผลเบื้องต้นได้ แต่อาจขาดการเชื่อมโยงกับทฤษฎีดนตรี | เลือกเพลงพอใช้ได้ อธิบายเหตุผลได้เพียงระดับความรู้สึกส่วนตัวเท่านั้น | เลือกเพลงไม่เข้ากัน ไม่สามารถอธิบายเหตุผลหรือเกณฑ์ในการจัดเรียงได้เลย |

## ✍️ 3. แบบประเมินการเขียนบทวิจารณ์เชิงสุนทรียศาสตร์ (Feldman's Method)
**ใช้สำหรับ:** ประเมินทักษะการคิดขั้นสูงทางดนตรีวิทยา (หน่วยที่ 4)

| ประเด็นการประเมิน | ดีเยี่ยม (4) | ดี (3) | พอใช้ (2) | ปรับปรุง (1) |
| :--- | :--- | :--- | :--- | :--- |
| **1. พรรณนาและวิเคราะห์ (Description & Analysis)** | ผ่าโครงสร้างดนตรี (จังหวะ, ทำนอง, เสียงประสาน, สีสันเสียง) มาพรรณนาประกอบการวิเคราะห์ได้อย่างละเอียดและใช้ศัพท์สังคีตถูกต้อง | ระบุองค์ประกอบทางดนตรีได้ถูกต้อง และพรรณนาภาพรวมของบทเพลงได้อย่างชัดเจน | กล่าวถึงองค์ประกอบดนตรีเพียงบางส่วน ขาดการวิเคราะห์เชิงลึก | ไม่กล่าวถึงองค์ประกอบทางดนตรีเลย เป็นเพียงการสรุปเนื้อเพลง |
| **2. ตีความและประเมินค่า (Interpretation & Judgment)** | ตีความอารมณ์เพลง และประเมินคุณค่าทางสุนทรียศาสตร์ของบทเพลงโดยอ้างอิงองค์ประกอบทางดนตรีวิทยา (เช่น จังหวะ, เสียงประสาน) มารองรับได้อย่างน้อย 2 ประเด็น | ประเมินคุณค่าของบทเพลงได้ดี มีการเชื่อมโยงกับอารมณ์ แต่อาจยังขาดเหตุผลทฤษฎีที่หนักแน่น | ตีความตามความรู้สึกส่วนตัวล้วนๆ ขาดหลักการหรือเหตุผลทางดนตรีมารองรับ | ไม่สามารถตีความอารมณ์เพลงได้ และไม่มีการประเมินคุณค่าทางดนตรีใดๆ |

## 👁️ 4. แบบสังเกตสุนทรียภาพและพัฒนาการทางดนตรี
**ใช้สำหรับ:** ประเมินคุณลักษณะและทักษะการคิดระดับสูง ระหว่างกิจกรรมการฟัง (หน่วยที่ 3-4)

| รายการพฤติกรรมเชิงประจักษ์ (Empirical Behavior) | ปฏิบัติสม่ำเสมอ (2) | ปฏิบัติบางครั้ง (1) | ไม่ปฏิบัติ (0) |
| :--- | :---: | :---: | :---: |
| 1. สามารถสะท้อนความรู้สึกจากการฟังโดยใช้ศัพท์ทางดนตรี (Musical Terms) อธิบายได้อย่างสมเหตุสมผล | | | |
| 2. วิพากษ์วิจารณ์ผลงานดนตรีของผู้อื่นโดยใช้หลักการทางดนตรีควบคู่กับมารยาทที่เหมาะสม | | | |
| 3. แสดงทัศนคติที่เปิดกว้างและวิเคราะห์ความงามของดนตรีต่างวัฒนธรรมที่ตนเองไม่คุ้นเคยได้ | | | |
| 4. สามารถเชื่อมโยงและเปรียบเทียบจุดเด่นของบทเพลงกับบริบททางสังคมและประวัติศาสตร์ได้ | | | |
| 5. แลกเปลี่ยนและยอมรับฟังมุมมองสุนทรียภาพทางดนตรีจากผู้อื่นอย่างสร้างสรรค์ | | | |
